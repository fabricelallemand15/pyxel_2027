Présentation

La leçon 3 a donné au joueur un déplacement horizontal commandé au clavier. Il se déplaçait pourtant dans un plan unique : sa hauteur ne changeait jamais.

Cette leçon ajoute une deuxième composante de mouvement. La gravité attire le joueur vers le sol en permanence, et la barre d’espace déclenche un saut lorsqu’il est posé.

Le saut n’est pas un déplacement soudain : c’est une vitesse verticale initiale, ensuite modifiée par la gravité à chaque image. Le joueur monte, ralentit, s’arrête un instant puis retombe.

Objectifs

À la fin de la leçon, vous devez pouvoir :

  1. ajouter une vitesse verticale dy au joueur ;
  2. appliquer une accélération constante vers le bas ;
  3. déclencher un saut avec pyxel.btnp() ;
  4. empêcher le joueur de sauter en l’air ;
  5. savoir si le joueur touche le sol grâce à un attribut ;
  6. expliquer la différence entre une action continue et une action ponctuelle.

Le sol est une constante

La tilemap place le dessus du sol à la ligne 28, soit la coordonnée 28 × 8 = 224. Le code ne lit pas la tilemap : il reprend cette valeur dans la constante GROUND_Y.

Les deux valeurs doivent rester cohérentes. Si la tilemap change, la constante doit changer aussi. La lecture réelle du décor sera étudiée avec les collisions.

Le code complet

Le projet contient toujours deux fichiers, main.py et res.pyxres, dans le même dossier.

import pyxel


SCREEN_WIDTH = 256
SCREEN_HEIGHT = 256
RESOURCE_FILE = "res.pyxres"

TILE_SIZE = 8
LEVEL_WIDTH = 32
LEVEL_HEIGHT = 32
GROUND_Y = 224

PLAYER_WIDTH = 8
PLAYER_HEIGHT = 8
PLAYER_SPEED = 2
GRAVITY = 1
JUMP_SPEED = -11
PLAYER_TILE_X = 0
PLAYER_TILE_Y = 0
PLAYER_START_X = 40
PLAYER_START_Y = GROUND_Y - PLAYER_HEIGHT

BACKGROUND_COLOR = pyxel.COLOR_DARK_BLUE
TEXT_COLOR = pyxel.COLOR_WHITE
TRANSPARENT_COLOR = 0

MUSIC = 0
JUMP_SOUND = 0


class Level:
    def __init__(self):
        self.width = LEVEL_WIDTH * TILE_SIZE
        self.height = LEVEL_HEIGHT * TILE_SIZE

    def draw(self):
        pyxel.bltm(
            0,
            0,
            0,
            0,
            0,
            self.width,
            self.height,
        )


class Player:
    def __init__(self, x, y):
        self.x = x
        self.y = y
        self.width = PLAYER_WIDTH
        self.height = PLAYER_HEIGHT
        self.dx = 0
        self.dy = 0
        self.is_on_ground = True

    def update(self):
        self.dx = 0

        if pyxel.btn(pyxel.KEY_LEFT):
            self.dx = -PLAYER_SPEED
        elif pyxel.btn(pyxel.KEY_RIGHT):
            self.dx = PLAYER_SPEED

        self.x += self.dx
        self.x = pyxel.clamp(
            self.x,
            0,
            pyxel.width - self.width,
        )

        if pyxel.btnp(pyxel.KEY_SPACE) and self.is_on_ground:
            self.dy = JUMP_SPEED
            pyxel.play(0, JUMP_SOUND)

        self.dy += GRAVITY
        self.y += self.dy

        if self.y + self.height >= GROUND_Y:
            self.y = GROUND_Y - self.height
            self.dy = 0
            self.is_on_ground = True
        else:
            self.is_on_ground = False

    def draw(self):
        pyxel.blt(
            self.x,
            self.y,
            0,
            PLAYER_TILE_X * TILE_SIZE,
            PLAYER_TILE_Y * TILE_SIZE,
            self.width,
            self.height,
            TRANSPARENT_COLOR,
        )


class Game:
    def __init__(self):
        pyxel.init(
            SCREEN_WIDTH,
            SCREEN_HEIGHT,
            title="Chapitre 4 - chute et saut",
        )
        pyxel.load(RESOURCE_FILE)

        self.level = Level()
        self.player = Player(
            PLAYER_START_X,
            PLAYER_START_Y,
        )

        pyxel.playm(MUSIC, loop=True)
        pyxel.run(self.update, self.draw)

    def update(self):
        if pyxel.btnp(pyxel.KEY_Q):
            pyxel.quit()

        self.player.update()

    def draw(self):
        pyxel.cls(BACKGROUND_COLOR)
        self.level.draw()

        pyxel.text(
            4,
            4,
            "Chapitre 4 - chute et saut",
            TEXT_COLOR,
        )
        pyxel.text(
            4,
            12,
            "Gauche et droite : marcher, Espace : sauter",
            TEXT_COLOR,
        )

        self.player.draw()


Game()

Le résultat attendu :

  • le joueur est posé sur le sol au démarrage ;
  • les flèches le déplacent horizontalement ;
  • la barre d’espace déclenche un saut d’environ 55 pixels de haut ;
  • le joueur retombe et se pose sur le sol ;
  • un saut ne peut pas être déclenché en l’air ;
  • le son du saut est joué à chaque départ ;
  • la touche Q ferme l’application.

Les plateformes ne sont pas encore solides

Le joueur traverse les plateformes : seule la ligne du sol arrête sa chute. Les plateformes deviendront praticables avec l’étude des collisions.

Comprendre le programme

Deux vitesses, deux directions

Le joueur possède maintenant deux vitesses :

  • dx pour le déplacement horizontal, calculé à partir des flèches ;
  • dy pour le déplacement vertical, modifié par la gravité et par le saut.

La position est mise à jour séparément dans chaque direction :

self.x += self.dx
self.y += self.dy

Séparer les deux directions simplifie le programme. Chaque axe a ses règles et ses limites, et les collisions pourront traiter les deux axes indépendamment.

La gravité, une accélération

self.dy += GRAVITY
self.y += self.dy

La gravité ne modifie pas la position : elle modifie la vitesse verticale.

À chaque image, dy augmente de GRAVITY, puis la position est mise à jour. Le joueur tombe donc de plus en plus vite : 1 pixel à la première image, 2 à la suivante, 3 ensuite, et ainsi de suite.

Position, vitesse, accélération

Une position indique où se trouve l’objet. Une vitesse indique de combien il se déplace par image. Une accélération indique de combien la vitesse change par image.

La gravité est une accélération : elle change la vitesse, la vitesse change la position.

Le saut

if pyxel.btnp(pyxel.KEY_SPACE) and self.is_on_ground:
    self.dy = JUMP_SPEED
    pyxel.play(0, JUMP_SOUND)

Le saut donne au joueur une vitesse verticale négative, dirigée vers le haut. Avec JUMP_SPEED = -11, le joueur monte d’abord vite, puis de moins en moins vite, parce que la gravité réduit sa vitesse à chaque image.

pyxel.btnp() est utilisé et non pyxel.btn() : un saut est une action ponctuelle. Avec btn(), maintenir la barre d’espace provoquerait un saut dès que le joueur touche le sol, sans aucune pause.

ToucheFonctionComportement
Flèches gauche et droitepyxel.btn()Déplacement continu
Barre d’espacepyxel.btnp()Action ponctuelle
Qpyxel.btnp()Action ponctuelle

Savoir si le joueur est au sol

if self.y + self.height >= GROUND_Y:
    self.y = GROUND_Y - self.height
    self.dy = 0
    self.is_on_ground = True
else:
    self.is_on_ground = False

Le bas du joueur se trouve à self.y + self.height. Tant que cette valeur reste inférieure à GROUND_Y, le joueur est au-dessus du sol.

Dès qu’elle atteint ou dépasse GROUND_Y, le joueur est replacé exactement sur le sol. Sa vitesse verticale est mise à zéro : sans cela, dy continuerait d’augmenter et la chute reprendrait à la première image suivante.

L’attribut is_on_ground mémorise le résultat. Il est vrai quand le joueur est posé, faux sinon.

Un attribut plutôt qu’un calcul répété

La condition de saut pourrait recalculer la position du sol. Utiliser un attribut rend la condition lisible et permettra plus tard de distinguer le sol des plateformes.

Pas de double saut

La condition de saut contient deux parties reliées par and :

pyxel.btnp(pyxel.KEY_SPACE) and self.is_on_ground

Un saut n’est déclenché que si la touche vient d’être pressée et si le joueur touche le sol. En l’air, is_on_ground vaut faux : une nouvelle pression sur la barre d’espace n’a aucun effet.

Le son du saut

Le son est joué dans Player.update(), au moment du déclenchement :

pyxel.play(0, JUMP_SOUND)

Le son numéro 0 est celui du saut dans le fichier de ressources. Le canal 0 est utilisé, comme dans les leçons précédentes.

Où jouer un son

Le joueur connaît la règle qui déclenche le saut : il peut donc jouer le son lui-même.

Une autre organisation consisterait à signaler le saut par un attribut et à laisser Game jouer le son. Cette forme ajoute une étape et ne sera utilisée que si plusieurs objets doivent réagir au même événement.

Les accents à l’écran

Le titre affiché dit « chute et saut » plutôt que « gravité » : l’accent de « gravité » n’existe pas dans la police (voir la leçon 1).

Erreurs fréquentes

Le joueur saute sans arrêt

pyxel.btn() a été utilisé pour la barre d’espace. Le saut se déclenche alors à chaque image où le joueur touche le sol, tant que la touche reste enfoncée.

if pyxel.btnp(pyxel.KEY_SPACE) and self.is_on_ground:

Le joueur saute plusieurs fois en l’air

La condition self.is_on_ground est absente. Le programme autorise alors un nouvel élan à chaque pression, même en plein saut.

Le joueur traverse le sol

Le test de collision avec le sol est absent ou placé avant la mise à jour de la position. L’ordre correct est :

  1. modifier dy avec la gravité ;
  2. ajouter dy à y ;
  3. tester le contact avec le sol.

Le joueur flotte ou s’enfonce

La constante GROUND_Y ne correspond pas au dessus du sol dessiné par la tilemap. Le sol commence à la ligne 28, soit la coordonnée 224.

GROUND_Y = 224

Expérimentations

Ces modifications sont facultatives.

Changer la hauteur du saut

JUMP_SPEED = -6

Le saut devient plus court. Une valeur trop faible empêche d’atteindre la première plateforme ; une valeur trop forte donne l’impression que le joueur flotte.

Changer la gravité

GRAVITY = 2

La chute est plus rapide et le saut plus sec. Modifier la gravité change aussi la hauteur atteinte : une gravité plus forte réduit la durée du saut.

Ajouter la flèche haut

if (
    pyxel.btnp(pyxel.KEY_SPACE)
    or pyxel.btnp(pyxel.KEY_UP)
) and self.is_on_ground:

La flèche du haut déclenche aussi le saut. La condition reste une action ponctuelle.

Afficher l’état du joueur

Ajoutez dans Game.draw(), après le texte existant :

pyxel.text(
    4,
    20,
    f"dy = {self.player.dy}",
    TEXT_COLOR,
)

La vitesse verticale affichée montre la progression de la chute et du saut image par image.

À retenir

  • dx gère l’horizontale, dy gère la verticale.
  • La gravité est une accélération : elle modifie dy, pas directement y.
  • Le saut donne une vitesse verticale négative.
  • pyxel.btnp() convient aux actions ponctuelles, pyxel.btn() aux déplacements continus.
  • is_on_ground empêche le double saut.
  • Le contact avec le sol remet la vitesse verticale à zéro.
  • Le son du saut est joué au moment du déclenchement.
