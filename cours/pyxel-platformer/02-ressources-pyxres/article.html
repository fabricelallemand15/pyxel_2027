Présentation

La leçon 1 utilisait uniquement des formes géométriques. Cette leçon introduit les ressources graphiques et sonores du jeu.

Le programme charge un fichier res.pyxres placé à côté de main.py. Ce fichier contient :

  • les images du joueur et des éléments du décor ;
  • une tilemap décrivant le niveau ;
  • des bruitages ;
  • une musique.

Le joueur reste représenté par un objet Player, mais il est maintenant dessiné avec une image extraite du fichier de ressources. Le niveau est dessiné avec pyxel.bltm(). Un bruitage est joué à chaque rebond et une musique accompagne la scène.

Deux fichiers, un seul programme

Le projet contient désormais deux fichiers :

main.py
res.pyxres

Le code Python reste entièrement contenu dans main.py. Le fichier .pyxres ne contient pas de code : il ne contient que des données.

Les deux fichiers doivent rester dans le même dossier.

Objectifs

À la fin de la leçon, vous devez pouvoir :

  1. expliquer à quoi sert un fichier .pyxres ;
  2. charger les ressources avec pyxel.load() ;
  3. afficher une image avec pyxel.blt() ;
  4. dessiner une tilemap avec pyxel.bltm() ;
  5. jouer un bruitage avec pyxel.play() ;
  6. jouer une musique avec pyxel.playm() ;
  7. utiliser la couleur transparente d’un sprite.

La taille de la fenêtre à la Nuit du Code

Le règlement de la Nuit du Code impose une fenêtre de jeu de 128 × 128 pixels ou de 256 × 256 pixels.

La formation retient 256 × 256 pixels.

Ce choix présente trois avantages :

  • le décor laisse de la place à plusieurs plateformes et à une progression verticale ;
  • un niveau de 32 × 32 tuiles remplit exactement l’écran ;
  • les sprites de 8 × 8 pixels restent petits par rapport à la fenêtre, ce qui donne un rendu lisible et une impression d’espace.

Constante à ne pas modifier

SCREEN_WIDTH = 256
SCREEN_HEIGHT = 256

Ces deux constantes sont fixées pour toute la formation. Elles correspondent à l’une des deux tailles autorisées.

La variante 128 × 128 est également conforme au règlement. Elle ne change pas le principe du programme, mais elle modifie plusieurs valeurs :

  • SCREEN_WIDTH et SCREEN_HEIGHT passent à 128 ;
  • un écran affiche alors 16 × 16 tuiles au lieu de 32 × 32 ;
  • les positions du décor et du joueur doivent être revues ;
  • le niveau de référence devrait être redessiné ou parcouru avec une caméra plus tôt.

La formation conserve 256 × 256 pour laisser place au niveau complet sans caméra jusqu’à la leçon qui l’introduit.

Le fichier de ressources

Rôle du fichier

Un fichier .pyxres regroupe les données d’un projet Pyxel :

ContenuRôleUtilisation dans le code
Banques d’imagesDessins en pixelspyxel.blt()
TilemapsAssemblage de tuilespyxel.bltm()
SonsBruitages courtspyxel.play()
MusiquesSuites de sonspyxel.playm()

Le programme ne connaît pas le contenu du fichier. Il indique simplement quelle zone lire :

  • une image est désignée par des coordonnées en pixels dans une banque ;
  • une tuile de tilemap est désignée par des coordonnées de tuiles ;
  • un son est désigné par son numéro ;
  • une musique est désignée par son numéro.

Format technique

Un fichier .pyxres est une archive ZIP qui contient un unique fichier texte au format TOML. Les images y sont décrites pixel par pixel sous forme de valeurs de la palette Pyxel.

Ce détail n’est pas nécessaire pour utiliser les ressources. Il explique seulement pourquoi le fichier n’est pas lisible directement dans un éditeur de texte.

Récupérer le fichier de la formation

Le fichier res.pyxres de cette leçon est fourni avec le cours. Il doit être placé dans le même dossier que main.py.

Import dans PyxelStudio

Selon la version de PyxelStudio, un fichier de ressources peut être importé dans le projet, puis ouvert dans l’éditeur de ressources.

Si l’import de fichier n’est pas disponible, il est possible de reconstruire les ressources dans l’éditeur intégré en suivant les indications des sections suivantes. Le code Python, lui, ne change pas.

Charger les ressources

Le chargement se fait une seule fois, au démarrage, avant toute utilisation :

pyxel.load(RESOURCE_FILE)

avec :

RESOURCE_FILE = "res.pyxres"

Emplacement du fichier

Si le fichier n’est pas dans le même dossier que main.py, Pyxel affiche une erreur du type :

Failed to open file 'res.pyxres'

Il faut alors vérifier le nom du fichier et son emplacement.

Le chargement doit être placé après pyxel.init() et avant pyxel.run().

Afficher une image avec pyxel.blt()

Principe

pyxel.blt() copie une zone rectangulaire d’une banque d’images vers l’écran.

pyxel.blt(x, y, img, u, v, w, h, colkey)
ParamètreRôle
x, yPosition à l’écran, en pixels
imgNuméro de la banque d’images
u, vPosition de la zone dans la banque, en pixels
w, hLargeur et hauteur de la zone, en pixels
colkeyCouleur considérée comme transparente

La distinction entre x, y et u, v est importante :

  • x et y indiquent où dessiner sur l’écran ;
  • u et v indiquent quoi dessiner dans la banque d’images.

Dessiner le joueur

def draw(self):
    pyxel.blt(
        self.x,
        self.y,
        0,
        PLAYER_TILE_X * TILE_SIZE,
        PLAYER_TILE_Y * TILE_SIZE,
        self.width,
        self.height,
        TRANSPARENT_COLOR,
    )

Avec :

PLAYER_TILE_X = 0
PLAYER_TILE_Y = 0
TILE_SIZE = 8

La position dans la banque est calculée à partir de coordonnées de tuiles. La tuile (0, 0) correspond aux pixels (0, 0) de la banque.

Pour utiliser la tuile (2, 0), il suffit de modifier la constante :

PLAYER_TILE_X = 2

La couleur transparente

Un sprite est un petit rectangle qui contient un dessin, mais aussi des pixels inutiles autour du dessin.

Dans le fichier fourni, ces pixels utilisent la couleur 0 de la palette, le noir. Cette couleur est déclarée transparente :

TRANSPARENT_COLOR = 0

Sans cette indication, le sprite serait dessiné avec un rectangle noir autour du personnage.

Pourquoi éviter le noir dans le dessin

Si la couleur 0 sert de couleur transparente, aucun élément du sprite ne doit l’utiliser.

Les dessins de la formation utilisent donc le bleu nuit pour les contours et réservent le noir à la transparence.

Dessiner la tilemap avec pyxel.bltm()

Principe

Une tilemap est une grille de références vers des tuiles de 8 × 8 pixels. Chaque case ne contient pas un dessin : elle contient les coordonnées d’une tuile dans la banque d’images.

pyxel.bltm() copie une zone de tilemap vers l’écran.

pyxel.bltm(x, y, tm, u, v, w, h)
ParamètreRôle
x, yPosition à l’écran, en pixels
tmNuméro de la tilemap
u, vPosition dans la tilemap, en pixels
w, hLargeur et hauteur de la zone, en pixels

Comme pour blt(), les coordonnées u et v sont exprimées en pixels, même si la tilemap est organisée en tuiles.

La classe Level

class Level:
    def __init__(self):
        self.width = LEVEL_WIDTH * TILE_SIZE
        self.height = LEVEL_HEIGHT * TILE_SIZE

    def draw(self):
        pyxel.bltm(
            0,
            0,
            0,
            0,
            0,
            self.width,
            self.height,
        )

Avec :

LEVEL_WIDTH = 32
LEVEL_HEIGHT = 32

La classe Level respecte la même organisation que Player :

  • __init__() prépare les dimensions ;
  • draw() affiche l’élément.

Le niveau n’a pas encore de méthode update(), car il est immobile. Une méthode sera ajoutée lorsque le défilement du décor sera étudié.

Une case vide

Une case vide d’une tilemap contient les coordonnées d’une zone transparente de la banque d’images. Dans le fichier fourni, il s’agit de la tuile (5, 5).

Si une case vide référence par erreur la tuile (0, 0), le dessin du joueur apparaît répété sur tout le niveau.

Jouer un son et une musique

Un bruitage

pyxel.play(ch, snd)
ParamètreRôle
chNuméro du canal, de 0 à 3
sndNuméro du son

Dans cette leçon, le bruitage numéro 1 est joué à chaque rebond :

pyxel.play(0, BOUNCE_SOUND)

avec :

BOUNCE_SOUND = 1

Le canal 0 est utilisé. Les canaux permettent de jouer plusieurs sons en même temps ; ils seront réutilisés pour les sauts et les collisions.

Détecter un rebond

Le joueur change de sens lorsqu’il atteint un bord. La classe Game compare la direction avant et après la mise à jour :

def update(self):
    if pyxel.btnp(pyxel.KEY_Q):
        pyxel.quit()

    direction = self.player.dx
    self.player.update()

    if self.player.dx != direction:
        pyxel.play(0, BOUNCE_SOUND)

Cette détection reste volontairement simple. Elle ne décrit pas une règle de jeu, seulement un événement visuel : le joueur vient de changer de direction.

Une musique

pyxel.playm(MUSIC, loop=True)

avec :

MUSIC = 0

La musique 0 est lancée au démarrage et rejouée en boucle. Elle utilise deux canaux : une mélodie et un accompagnement.

Pour arrêter la musique :

pyxel.stop()

Charger avant de jouer

Un son ou une musique ne peut pas être joué avant le chargement des ressources.

L’ordre correct est :

  1. pyxel.init() ;
  2. pyxel.load() ;
  3. pyxel.playm() ;
  4. pyxel.run().

Le code complet

import pyxel


SCREEN_WIDTH = 256
SCREEN_HEIGHT = 256
RESOURCE_FILE = "res.pyxres"

TILE_SIZE = 8
LEVEL_WIDTH = 32
LEVEL_HEIGHT = 32

PLAYER_WIDTH = 8
PLAYER_HEIGHT = 8
PLAYER_SPEED = 1
PLAYER_TILE_X = 0
PLAYER_TILE_Y = 0
PLAYER_START_X = 40
PLAYER_START_Y = 216

BACKGROUND_COLOR = pyxel.COLOR_DARK_BLUE
TEXT_COLOR = pyxel.COLOR_WHITE
TRANSPARENT_COLOR = 0

BOUNCE_SOUND = 1
MUSIC = 0


class Level:
    def __init__(self):
        self.width = LEVEL_WIDTH * TILE_SIZE
        self.height = LEVEL_HEIGHT * TILE_SIZE

    def draw(self):
        pyxel.bltm(
            0,
            0,
            0,
            0,
            0,
            self.width,
            self.height,
        )


class Player:
    def __init__(self, x, y):
        self.x = x
        self.y = y
        self.width = PLAYER_WIDTH
        self.height = PLAYER_HEIGHT
        self.dx = PLAYER_SPEED

    def update(self):
        self.x += self.dx

        if self.x <= 0:
            self.x = 0
            self.dx = abs(self.dx)
        elif self.x + self.width >= pyxel.width:
            self.x = pyxel.width - self.width
            self.dx = -abs(self.dx)

    def draw(self):
        pyxel.blt(
            self.x,
            self.y,
            0,
            PLAYER_TILE_X * TILE_SIZE,
            PLAYER_TILE_Y * TILE_SIZE,
            self.width,
            self.height,
            TRANSPARENT_COLOR,
        )


class Game:
    def __init__(self):
        pyxel.init(
            SCREEN_WIDTH,
            SCREEN_HEIGHT,
            title="Leçon 2 - ressources",
        )
        pyxel.load(RESOURCE_FILE)

        self.level = Level()
        self.player = Player(
            PLAYER_START_X,
            PLAYER_START_Y,
        )

        pyxel.playm(MUSIC, loop=True)
        pyxel.run(self.update, self.draw)

    def update(self):
        if pyxel.btnp(pyxel.KEY_Q):
            pyxel.quit()

        direction = self.player.dx
        self.player.update()

        if self.player.dx != direction:
            pyxel.play(0, BOUNCE_SOUND)

    def draw(self):
        pyxel.cls(BACKGROUND_COLOR)
        self.level.draw()

        pyxel.text(
            4,
            4,
            "Leçon 2 - ressources",
            TEXT_COLOR,
        )
        pyxel.text(
            4,
            12,
            "Images, tilemap et audio",
            TEXT_COLOR,
        )

        self.player.draw()


Game()

Erreurs fréquentes

Failed to open file 'res.pyxres'

Le fichier n’est pas trouvé. Vérifiez :

  • son nom exact ;
  • sa présence dans le même dossier que main.py ;
  • l’absence d’une double extension du type res.pyxres.txt.

Un rectangle noir entoure le joueur

La couleur transparente n’est pas indiquée. Vérifiez le dernier argument de pyxel.blt() :

TRANSPARENT_COLOR,

Le joueur apparaît partout dans le niveau

Les cases vides de la tilemap référencent une tuile dessinée. Il faut corriger la tilemap dans l’éditeur de ressources et placer une tuile transparente dans les cases vides.

Aucun son n’est entendu

Plusieurs causes sont possibles :

  • pyxel.load() a été oublié ;
  • le numéro de son est erroné ;
  • le son a été joué avant le chargement des ressources ;
  • le volume de l’environnement est coupé.

Le décor ne s’affiche pas

Vérifiez l’ordre des arguments de pyxel.bltm() : la position à l’écran vient d’abord, le numéro de tilemap ensuite.

pyxel.bltm(x, y, tm, u, v, w, h)

Expérimentations

Ces modifications sont facultatives.

Utiliser une autre image du joueur

Remplacez :

PLAYER_TILE_X = 0

par :

PLAYER_TILE_X = 2

Le joueur utilise alors une image de marche.

Afficher une pièce isolée

Ajoutez dans Game.draw(), avant self.player.draw() :

pyxel.blt(
    64,
    40,
    0,
    3 * TILE_SIZE,
    1 * TILE_SIZE,
    8,
    8,
    TRANSPARENT_COLOR,
)

La tuile (3, 1) de la banque 0 apparaît à la position (64, 40) de l’écran.

Changer le bruitage

Remplacez :

BOUNCE_SOUND = 1

par :

BOUNCE_SOUND = 0

Le rebond utilise alors le son du saut.

Changer la musique

Ajoutez plusieurs musiques dans l’éditeur de ressources, puis modifiez :

MUSIC = 0

Modifier le niveau

Dans l’éditeur de tilemap, déplacez les plateformes ou ajoutez des pièces. Le code Python ne change pas : le niveau est entièrement décrit par la tilemap.

Un niveau sans modification du code

Cette propriété est importante pour la suite : le décor peut être retravaillé dans l’éditeur sans toucher au programme. Seules les positions logiques, comme le point de départ du joueur, doivent rester cohérentes avec le dessin.

À retenir

  • La fenêtre de jeu mesure 256 × 256 pixels, l’une des deux tailles autorisées par la Nuit du Code.
  • Un fichier .pyxres contient les images, les tilemaps, les sons et les musiques.
  • pyxel.load() charge les ressources et doit être appelé avant leur utilisation.
  • pyxel.blt() affiche une zone d’une banque d’images.
  • pyxel.bltm() affiche une zone d’une tilemap.
  • colkey rend une couleur transparente : ici la couleur 0.
  • pyxel.play() joue un bruitage sur un canal.
  • pyxel.playm() joue une musique.
  • Le décor est décrit dans la tilemap, pas dans le code Python.

Dans la prochaine leçon, le déplacement automatique est remplacé par les contrôles du clavier. La classe Player recevra une méthode update() qui lit les touches gauche et droite.
