Présentation

Dans cette première leçon, nous créons la structure minimale d’un jeu Pyxel.

Le programme affiche une fenêtre, un sol et un joueur représenté par un rectangle. Le joueur se déplace automatiquement et rebondit sur les bords de l’écran.

Cette étape introduit deux idées qui resteront présentes dans toute la formation :

  • la boucle de jeu sépare la mise à jour de l’état et le dessin ;
  • chaque élément du jeu est représenté par un objet Python possédant ses propres méthodes.

Les images, la tilemap, les sons et la musique seront ajoutés dans la prochaine leçon avec le fichier res.pyxres.

Fichier de la leçon

Cette leçon n’utilise encore aucune ressource graphique externe. Le seul fichier à copier dans l’éditeur est donc main.py.

Le projet complet de la formation utilisera ensuite deux fichiers placés dans le même dossier :

main.py
res.pyxres

Objectifs

À la fin de la leçon, vous devez pouvoir :

  1. initialiser une fenêtre Pyxel avec pyxel.init() ;
  2. lancer une boucle avec pyxel.run() ;
  3. distinguer le rôle de update() et de draw() ;
  4. créer une classe avec __init__() ;
  5. utiliser des attributs avec self ;
  6. créer un objet Player et lui demander de se mettre à jour et de se dessiner.

Préparer le projet dans PyxelStudio

Ouvrez PyxelStudio dans Capytale et créez un projet Python.

Dans cette leçon, le code est placé dans main.py. Si l’environnement propose déjà un fichier res.pyxres, vous pouvez le conserver, mais il ne sera pas chargé par le programme.

Ne pas charger encore la ressource

Le fichier .pyxres sera étudié dans la leçon 2. Laisser cette première version utiliser uniquement des formes géométriques permet de se concentrer sur la boucle de jeu et la structure des classes.

Le code complet

Copiez le code suivant dans main.py, puis exécutez-le dans PyxelStudio.

import pyxel


SCREEN_WIDTH = 256
SCREEN_HEIGHT = 256
GROUND_Y = 224

PLAYER_WIDTH = 8
PLAYER_HEIGHT = 8
PLAYER_SPEED = 1

BACKGROUND_COLOR = pyxel.COLOR_DARK_BLUE
GROUND_COLOR = pyxel.COLOR_GREEN
PLAYER_COLOR = pyxel.COLOR_YELLOW
TEXT_COLOR = pyxel.COLOR_WHITE


class Player:
    def __init__(self, x, y):
        self.x = x
        self.y = y
        self.width = PLAYER_WIDTH
        self.height = PLAYER_HEIGHT
        self.dx = PLAYER_SPEED

    def update(self):
        self.x += self.dx

        if self.x <= 0:
            self.x = 0
            self.dx = abs(self.dx)
        elif self.x + self.width >= pyxel.width:
            self.x = pyxel.width - self.width
            self.dx = -abs(self.dx)

    def draw(self):
        pyxel.rect(
            self.x,
            self.y,
            self.width,
            self.height,
            PLAYER_COLOR,
        )


class Game:
    def __init__(self):
        pyxel.init(
            SCREEN_WIDTH,
            SCREEN_HEIGHT,
            title="Chapitre 1 - Boucle de jeu",
        )

        self.player = Player(
            20,
            GROUND_Y - PLAYER_HEIGHT,
        )

        pyxel.run(self.update, self.draw)

    def update(self):
        if pyxel.btnp(pyxel.KEY_Q):
            pyxel.quit()

        self.player.update()

    def draw(self):
        pyxel.cls(BACKGROUND_COLOR)
        pyxel.rect(
            0,
            GROUND_Y,
            pyxel.width,
            pyxel.height - GROUND_Y,
            GROUND_COLOR,
        )
        pyxel.text(
            4,
            4,
            "Chapitre 1 - boucle de jeu",
            TEXT_COLOR,
        )
        pyxel.text(
            4,
            12,
            f"Image {pyxel.frame_count}",
            TEXT_COLOR,
        )

        self.player.draw()


Game()

Le résultat attendu est le suivant :

  • une fenêtre de 256 × 256 pixels ;
  • un fond bleu foncé ;
  • un sol vert ;
  • un carré jaune qui se déplace ;
  • le carré qui rebondit sur les bords ;
  • le numéro d’image affiché en haut à gauche ;
  • la touche Q qui ferme l’application.

Comprendre le programme

Importer Pyxel

import pyxel

Cette instruction importe le module Pyxel. Elle donne accès aux fonctions utilisées pour :

  • créer la fenêtre ;
  • dessiner ;
  • lire le clavier ;
  • lancer la boucle de jeu ;
  • quitter l’application.

Définir des constantes

SCREEN_WIDTH = 256
SCREEN_HEIGHT = 256
GROUND_Y = 224

Ces constantes décrivent la configuration générale du jeu.

SCREEN_WIDTH et SCREEN_HEIGHT valent 256. Cette valeur correspond à l’une des deux tailles de fenêtre autorisées à la Nuit du Code :

128 × 128 pixels
256 × 256 pixels

La formation conserve 256 × 256 pour toute sa durée. La leçon 2 détaille ce choix et présente la variante 128 × 128.

GROUND_Y est la coordonnée verticale du haut du sol. Dans Pyxel, l’origine du repère est située en haut à gauche :

  • les valeurs de x augmentent vers la droite ;
  • les valeurs de y augmentent vers le bas.

Les dimensions du joueur et sa vitesse sont également regroupées dans des constantes :

PLAYER_WIDTH = 8
PLAYER_HEIGHT = 8
PLAYER_SPEED = 1

Une constante permet de modifier un réglage à un seul endroit du programme.

Créer la classe Player

class Player:
    def __init__(self, x, y):
        self.x = x
        self.y = y
        self.width = PLAYER_WIDTH
        self.height = PLAYER_HEIGHT
        self.dx = PLAYER_SPEED

La classe Player décrit un élément du jeu : le joueur.

La méthode __init__() est appelée lorsqu’un objet est créé. Elle reçoit sa position initiale et enregistre les informations nécessaires dans les attributs de l’objet.

Par exemple :

self.x = x

signifie que l’objet mémorise sa position horizontale dans l’attribut x.

Le préfixe self désigne l’objet courant. Deux objets Player pourraient donc avoir des valeurs différentes pour self.x et self.y.

Classe et objet

Player est une classe : elle décrit ce qu’est un joueur.

class Player:
    ...

Un objet est une instance concrète de cette classe :

player = Player(20, 80)

Dans le programme, l’objet sera créé par Game et stocké dans self.player.

Mettre à jour le joueur

def update(self):
    self.x += self.dx

La méthode update() décrit l’évolution du joueur pendant une image.

L’attribut dx représente le déplacement horizontal. Avec PLAYER_SPEED = 1, le joueur avance d’un pixel à chaque mise à jour.

La méthode ne dessine rien. Elle modifie uniquement l’état de l’objet.

Gérer les bords de l’écran

if self.x <= 0:
    self.x = 0
    self.dx = abs(self.dx)
elif self.x + self.width >= pyxel.width:
    self.x = pyxel.width - self.width
    self.dx = -abs(self.dx)

Le premier test concerne le bord gauche.

  • Si self.x devient négatif, le joueur dépasse l’écran.
  • On replace alors self.x à zéro.
  • On rend dx positif afin que le joueur reparte vers la droite.

Le second test concerne le bord droit.

  • self.x + self.width représente la position du bord droit du joueur.
  • pyxel.width représente la largeur de l’écran.
  • On replace le joueur pour que son bord droit reste visible.
  • On rend dx négatif afin qu’il reparte vers la gauche.

La fonction abs() renvoie la valeur absolue d’un nombre. Elle permet d’obtenir la valeur positive de la vitesse avant de choisir son signe.

Dessiner le joueur

def draw(self):
    pyxel.rect(
        self.x,
        self.y,
        self.width,
        self.height,
        PLAYER_COLOR,
    )

La méthode draw() représente le joueur à l’écran.

pyxel.rect() reçoit :

  1. la coordonnée x du coin supérieur gauche ;
  2. la coordonnée y du coin supérieur gauche ;
  3. la largeur ;
  4. la hauteur ;
  5. la couleur.

La méthode lit les attributs du joueur, mais ne les modifie pas.

La séparation entre update() et draw() sera conservée pour les autres classes du jeu : ennemis, objets à ramasser et niveau.

La classe Game

Initialiser le jeu

class Game:
    def __init__(self):
        pyxel.init(
            SCREEN_WIDTH,
            SCREEN_HEIGHT,
            title="Chapitre 1 - Boucle de jeu",
        )

La classe Game représente le jeu dans son ensemble.

Elle est responsable de :

  • créer la fenêtre ;
  • posséder les objets du jeu ;
  • coordonner leur mise à jour ;
  • coordonner leur dessin.

pyxel.init() initialise une fenêtre de 256 × 256 pixels et lui donne un titre.

Créer le joueur

self.player = Player(
    20,
    GROUND_Y - PLAYER_HEIGHT,
)

Le jeu crée un objet Player et le conserve dans l’attribut self.player.

La position verticale est calculée ainsi :

GROUND_Y - PLAYER_HEIGHT

Le bas du joueur se trouve donc exactement au niveau du haut du sol.

Lancer la boucle

pyxel.run(self.update, self.draw)

Cette instruction lance l’application Pyxel et lui fournit les deux méthodes à appeler pendant le jeu :

  • self.update pour la logique ;
  • self.draw pour l’affichage.

On peut représenter l’organisation générale ainsi :

Game
├── update()
│   └── player.update()
└── draw()
    └── player.draw()

La classe Game coordonne les objets, mais le joueur reste responsable de son propre déplacement et de son propre dessin.

La méthode Game.update()

def update(self):
    if pyxel.btnp(pyxel.KEY_Q):
        pyxel.quit()

    self.player.update()

La méthode commence par vérifier si la touche Q vient d’être pressée.

btnp() est adapté à une action ponctuelle : il renvoie vrai au moment où la touche est pressée. La différence entre btn() et btnp() sera étudiée lors de l’ajout des contrôles du joueur.

Ensuite, Game demande au joueur de mettre à jour son état :

self.player.update()

La classe Game ne modifie donc pas directement self.player.x. Elle délègue cette opération à l’objet qui possède la responsabilité du joueur.

La méthode Game.draw()

Effacer l’image et dessiner le sol

def draw(self):
    pyxel.cls(BACKGROUND_COLOR)
    pyxel.rect(
        0,
        GROUND_Y,
        pyxel.width,
        pyxel.height - GROUND_Y,
        GROUND_COLOR,
    )

À chaque image, l’écran est effacé avec pyxel.cls().

Le sol est un rectangle qui commence à GROUND_Y et s’étend jusqu’en bas de l’écran.

Le dessin est recommencé à chaque image. Un élément dessiné dans l’image précédente ne reste pas automatiquement présent.

Afficher le texte

pyxel.text(
    4,
    4,
    "Chapitre 1 - boucle de jeu",
    TEXT_COLOR,
)
pyxel.text(
    4,
    12,
    f"Image {pyxel.frame_count}",
    TEXT_COLOR,
)

pyxel.text() affiche une chaîne à une position donnée.

Ni accents, ni cédille à l’écran

La police intégrée de Pyxel ne contient que les caractères ASCII imprimables. Une lettre accentuée ou une cédille n’est pas dessinée : « Leçon » s’afficherait « Lecon », et « flèches » s’afficherait « flches ».

Les textes de l’interface évitent donc les accents. Le mot Chapitre remplace Leçon, le mot Restantes remplace Pièces, et les commandes s’écrivent Gauche et droite : marcher. Toutes les leçons suivent cette règle.

Le titre passé à pyxel.init() est dessiné par le système et non par cette police ; il reprend pourtant le même texte, pour que le code reste cohérent.

pyxel.frame_count est un compteur de frames fourni par Pyxel. Il augmente au cours de l’exécution et pourra être utilisé pour créer des animations.

Dessiner le joueur

self.player.draw()

La classe Game demande au joueur de se dessiner.

Cette organisation est déjà celle d’un jeu contenant plusieurs objets. Plus tard, Game.draw() demandera de la même manière à chaque ennemi ou objet à ramasser de se dessiner.

Créer l’objet Game

La dernière ligne du fichier est :

Game()

Une classe ne crée pas automatiquement un objet lorsqu’elle est définie. Cette instruction crée l’objet principal du jeu.

Son constructeur est alors exécuté dans l’ordre suivant :

  1. Pyxel est initialisé ;
  2. le joueur est créé ;
  3. la boucle de jeu est lancée.

Sans Game(), le programme définirait les classes mais n’ouvrirait aucune fenêtre.

Comprendre la boucle de jeu

Le programme peut maintenant être résumé ainsi :

création de Game
        ↓
initialisation de Pyxel
        ↓
création de Player
        ↓
appel répété de Game.update()
        ↓
appel répété de Game.draw()

Pendant la mise à jour :

Game.update()
    → Player.update()

Pendant le dessin :

Game.draw()
    → dessiner le décor
    → afficher le texte
    → Player.draw()

La logique de déplacement reste dans Player.update(). Le dessin du joueur reste dans Player.draw().

Erreurs fréquentes

NameError

Vérifiez l’orthographe des noms : Player, Game, PLAYER_WIDTH, pyxel.

IndentationError

Le contenu d’une classe ou d’une méthode doit être décalé vers la droite. Les lignes appartenant à la même méthode doivent avoir la même indentation.

AttributeError

Vérifiez que les attributs sont écrits avec self, par exemple self.x et self.y, et que leur nom est identique dans __init__(), update() et draw().

Aucune fenêtre ne s’ouvre

Vérifiez que la dernière ligne du fichier est bien présente :

Game()

Expérimentations

Ces modifications sont facultatives. Elles permettent de vérifier le rôle des attributs et des constantes.

Modifier la vitesse

Remplacez :

PLAYER_SPEED = 1

par :

PLAYER_SPEED = 3

Observez la différence dans le déplacement.

Modifier les couleurs

Essayez une autre constante de couleur, par exemple :

PLAYER_COLOR = pyxel.COLOR_RED

Modifier la hauteur du sol

Changez :

GROUND_Y = 224

Observez pourquoi il faut également recalculer la position initiale du joueur.

Ajouter un second objet

Dans Game.__init__(), ajoutez un deuxième joueur :

self.other_player = Player(
    80,
    GROUND_Y - PLAYER_HEIGHT,
)

Puis ajoutez les appels correspondants :

self.other_player.update()

dans Game.update(), et :

self.other_player.draw()

dans Game.draw().

Les deux objets utiliseront la même classe, mais chacun conservera sa propre position.

À retenir

  • pyxel.init() initialise la fenêtre.
  • pyxel.run(update, draw) lance la boucle de jeu.
  • update() modifie l’état du jeu.
  • draw() affiche l’état courant.
  • Une classe décrit un type d’objet.
  • self désigne l’objet courant.
  • Game coordonne les objets du jeu.
  • Player connaît son déplacement et son dessin.
  • Game() crée l’objet principal et démarre l’application.

Dans la prochaine leçon, le rectangle du joueur et le décor seront remplacés ou complétés par des éléments créés dans l’éditeur de ressources Pyxel et chargés depuis res.pyxres.
