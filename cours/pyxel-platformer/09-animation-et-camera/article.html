Animation et caméra

Animer le joueur avec ses quatre images, retourner le sprite et faire défiler un niveau plus large que l’écran

Présentation

Depuis la leçon 2, la banque d’images contient quatre dessins du joueur. Un seul est utilisé : le personnage est toujours identique, qu’il marche, s’arrête ou saute. Cette leçon les fait tous servir.

Le personnage change d’image selon son activité : deux images alternées pendant la marche, une image au repos, une image en l’air. Il se retourne aussi, sans nouveau dessin : une largeur négative suffit.

Le décor, lui, s’agrandit. Le niveau du fichier de ressources mesure 512 pixels de large, deux fois la fenêtre. Jusqu’ici, le programme n’en dessinait que la moitié gauche. Cette leçon ajoute une caméra : un décalage appliqué au moment du dessin, qui laisse voir la partie du niveau où se trouve le joueur.

Objectifs

À la fin de la leçon, vous devez pouvoir :

  1. choisir une image de sprite selon l’état du personnage ;
  2. utiliser pyxel.frame_count pour rythmer une animation ;
  3. retourner un sprite horizontalement ;
  4. dessiner un niveau plus grand que l’écran ;
  5. calculer et appliquer un décalage de caméra ;
  6. distinguer coordonnées du monde et coordonnées de l’écran.

Le niveau existait déjà

Le fichier res.pyxres contient un niveau de 64 cases de large depuis le début de la formation. Les leçons 2 à 8 n’en dessinaient que la moitié gauche, large de 256 pixels. La caméra ne modifie donc pas les ressources : elle change la façon de les dessiner.

Le code complet

import pyxel


SCREEN_WIDTH = 256
SCREEN_HEIGHT = 256
RESOURCE_FILE = "res.pyxres"

TILE_SIZE = 8
LEVEL_WIDTH = 64
LEVEL_HEIGHT = 32
GROUND_Y = 224
SOLID_TILES = [
    (0, 1),
    (1, 1),
    (2, 1),
]
COIN_TILE = (3, 1)
ENEMY_TILE = (4, 0)
EMPTY_TILE = (5, 5)

PLAYER_WIDTH = 8
PLAYER_HEIGHT = 8
PLAYER_SPEED = 2
GRAVITY = 1
JUMP_SPEED = -11
PLAYER_IDLE_TILE = (0, 0)
PLAYER_JUMP_TILE = (1, 0)
PLAYER_WALK_TILES = [
    (2, 0),
    (3, 0),
]
ANIMATION_SPEED = 6
PLAYER_START_X = 8
PLAYER_START_Y = GROUND_Y - PLAYER_HEIGHT

ENEMY_SPEED = 1

BACKGROUND_COLOR = pyxel.COLOR_DARK_BLUE
TEXT_COLOR = pyxel.COLOR_WHITE
TRANSPARENT_COLOR = 0

MUSIC = 0
JUMP_SOUND = 0
COIN_SOUND = 1
HIT_SOUND = 2


class Coin:
    def __init__(self, x, y):
        self.x = x
        self.y = y
        self.width = TILE_SIZE
        self.height = TILE_SIZE
        self.is_alive = True

    def update(self):
        pass

    def draw(self):
        tile_x, tile_y = COIN_TILE
        pyxel.blt(
            self.x,
            self.y,
            0,
            tile_x * TILE_SIZE,
            tile_y * TILE_SIZE,
            self.width,
            self.height,
            TRANSPARENT_COLOR,
        )


class Enemy:
    def __init__(self, x, y, min_x, max_x):
        self.x = x
        self.y = y
        self.width = TILE_SIZE
        self.height = TILE_SIZE
        self.dx = ENEMY_SPEED
        self.min_x = min_x
        self.max_x = max_x

    def update(self):
        self.x += self.dx

        if self.x < self.min_x:
            self.x = self.min_x
            self.dx = ENEMY_SPEED
        elif self.x > self.max_x:
            self.x = self.max_x
            self.dx = -ENEMY_SPEED

    def draw(self):
        tile_x, tile_y = ENEMY_TILE
        pyxel.blt(
            self.x,
            self.y,
            0,
            tile_x * TILE_SIZE,
            tile_y * TILE_SIZE,
            self.width,
            self.height,
            TRANSPARENT_COLOR,
        )


class Level:
    def __init__(self):
        self.tilemap = pyxel.tilemaps[0]
        self.width = LEVEL_WIDTH * TILE_SIZE
        self.height = LEVEL_HEIGHT * TILE_SIZE

    def draw(self):
        pyxel.bltm(
            0,
            0,
            self.tilemap,
            0,
            0,
            self.width,
            self.height,
        )

    def move_player(self, x, y, dx, dy):
        return self.tilemap.collide(
            x,
            y,
            PLAYER_WIDTH,
            PLAYER_HEIGHT,
            dx,
            dy,
            SOLID_TILES,
        )

    def take_coins(self):
        positions = []

        for tile_y in range(LEVEL_HEIGHT):
            for tile_x in range(LEVEL_WIDTH):
                if self.tilemap.pget(tile_x, tile_y) == COIN_TILE:
                    self.tilemap.pset(tile_x, tile_y, EMPTY_TILE)
                    positions.append(
                        (tile_x * TILE_SIZE, tile_y * TILE_SIZE),
                    )

        return positions


class Player:
    def __init__(self, x, y, level):
        self.x = x
        self.y = y
        self.width = PLAYER_WIDTH
        self.height = PLAYER_HEIGHT
        self.dx = 0
        self.dy = 0
        self.is_on_ground = True
        self.is_facing_right = True
        self.tile = PLAYER_IDLE_TILE
        self.level = level

    def update(self):
        self.dx = 0

        if pyxel.btn(pyxel.KEY_LEFT):
            self.dx = -PLAYER_SPEED
            self.is_facing_right = False
        elif pyxel.btn(pyxel.KEY_RIGHT):
            self.dx = PLAYER_SPEED
            self.is_facing_right = True

        if pyxel.btnp(pyxel.KEY_SPACE) and self.is_on_ground:
            self.dy = JUMP_SPEED
            pyxel.play(0, JUMP_SOUND)

        self.dy += GRAVITY

        was_falling = self.dy > 0
        self.dx, self.dy = self.level.move_player(
            self.x,
            self.y,
            self.dx,
            self.dy,
        )

        self.x += self.dx
        self.x = pyxel.clamp(
            self.x,
            0,
            self.level.width - self.width,
        )
        self.y += self.dy

        self.is_on_ground = was_falling and self.dy == 0
        self.choose_tile()

    def draw(self):
        tile_x, tile_y = self.tile

        if self.is_facing_right:
            width = self.width
        else:
            width = -self.width

        pyxel.blt(
            self.x,
            self.y,
            0,
            tile_x * TILE_SIZE,
            tile_y * TILE_SIZE,
            width,
            self.height,
            TRANSPARENT_COLOR,
        )

    def choose_tile(self):
        if not self.is_on_ground:
            self.tile = PLAYER_JUMP_TILE
        elif self.dx != 0:
            index = pyxel.frame_count // ANIMATION_SPEED % 2
            self.tile = PLAYER_WALK_TILES[index]
        else:
            self.tile = PLAYER_IDLE_TILE


class Game:
    def __init__(self):
        pyxel.init(
            SCREEN_WIDTH,
            SCREEN_HEIGHT,
            title="Leçon 9 - animation et caméra",
        )
        pyxel.load(RESOURCE_FILE)

        self.level = Level()
        self.player = Player(
            PLAYER_START_X,
            PLAYER_START_Y,
            self.level,
        )

        self.coins = []
        for x, y in self.level.take_coins():
            self.coins.append(Coin(x, y))

        self.enemies = [
            Enemy(88, 216, 88, 160),
            Enemy(104, 144, 104, 160),
            Enemy(320, 216, 288, 440),
        ]

        self.score = 0
        self.is_game_over = False

        pyxel.playm(MUSIC, loop=True)
        pyxel.run(self.update, self.draw)

    def update(self):
        if pyxel.btnp(pyxel.KEY_Q):
            pyxel.quit()

        if self.is_game_over:
            return

        self.player.update()

        for coin in self.coins:
            coin.update()

        for enemy in self.enemies:
            enemy.update()

        self.check_coins()
        self.check_enemies()

    def draw(self):
        pyxel.cls(BACKGROUND_COLOR)

        camera_x = pyxel.clamp(
            self.player.x + self.player.width // 2 - pyxel.width // 2,
            0,
            self.level.width - pyxel.width,
        )
        pyxel.camera(camera_x, 0)

        self.level.draw()

        for coin in self.coins:
            coin.draw()

        for enemy in self.enemies:
            enemy.draw()

        self.player.draw()

        pyxel.camera()

        pyxel.text(
            4,
            4,
            "Leçon 9 - animation et caméra",
            TEXT_COLOR,
        )
        pyxel.text(
            4,
            12,
            "Flèches : déplacer, Espace : sauter",
            TEXT_COLOR,
        )
        pyxel.text(
            4,
            20,
            f"Score : {self.score}  Pièces : {len(self.coins)}",
            TEXT_COLOR,
        )

        if self.is_game_over:
            pyxel.rect(48, 96, 160, 32, pyxel.COLOR_BLACK)
            pyxel.text(102, 100, "Partie perdue", pyxel.COLOR_RED)
            pyxel.text(110, 112, f"Score : {self.score}", TEXT_COLOR)

    def collide(self, a, b):
        return (
            a.x < b.x + b.width
            and a.x + a.width > b.x
            and a.y < b.y + b.height
            and a.y + a.height > b.y
        )

    def check_coins(self):
        for coin in self.coins:
            if self.collide(self.player, coin):
                coin.is_alive = False
                self.score += 1
                pyxel.play(1, COIN_SOUND)

        self.coins = [coin for coin in self.coins if coin.is_alive]

    def check_enemies(self):
        for enemy in self.enemies:
            if self.collide(self.player, enemy):
                self.is_game_over = True
                pyxel.play(2, HIT_SOUND)

Comprendre le programme

Les quatre images du joueur

La banque d’images contient quatre dessins de 8 × 8 pixels, côte à côte sur la ligne 0, et une tuile d’ennemi sur la même ligne :

TuileContenuUsage dans cette leçon
(0, 0)joueur au repos, image 0arrêt
(1, 0)joueur au repos, image 1saut
(2, 0)joueur en marche, image 0marche
(3, 0)joueur en marche, image 1marche

Les quatre images sont déclarées en constantes : une pour le repos, une pour le saut, et une liste pour les deux images de marche.

PLAYER_IDLE_TILE = (0, 0)
PLAYER_JUMP_TILE = (1, 0)
PLAYER_WALK_TILES = [
    (2, 0),
    (3, 0),
]
ANIMATION_SPEED = 6

Les images de marche sont dans une liste parce qu’elles s’utilisent à tour de rôle : un index de 0 ou 1 suffit à choisir.

Choisir l’image au bon moment

def choose_tile(self):
    if not self.is_on_ground:
        self.tile = PLAYER_JUMP_TILE
    elif self.dx != 0:
        index = pyxel.frame_count // ANIMATION_SPEED % 2
        self.tile = PLAYER_WALK_TILES[index]
    else:
        self.tile = PLAYER_IDLE_TILE

Trois cas, examinés dans cet ordre :

  1. le joueur n’est pas au sol : il saute, l’image de saut s’applique, même s’il se déplace ;
  2. il est au sol et se déplace : l’image de marche alterne ;
  3. il est au sol et immobile : l’image de repos s’applique.

L’ordre compte : un joueur qui saute en avant remplit deux conditions, et c’est la première qui décide.

La méthode est appelée à la fin de update(), une fois is_on_ground et dx connus. Avant, elle lirait les valeurs de l’image précédente.

dx après la collision

self.dx est le déplacement réellement autorisé, pas la touche pressée. Un joueur qui pousse contre un mur a donc dx égal à zéro et reprend l’image de repos : il ne « marche pas sur place ».

Le temps en images

pyxel.frame_count est un compteur fourni par Pyxel : il vaut 0 au lancement, puis augmente de 1 à chaque image. À trente images par seconde, une seconde correspond à trente unités.

L’expression pyxel.frame_count // ANIMATION_SPEED % 2 transforme ce compteur en 0 ou 1, en changeant toutes les six images :

frame_count// 6% 2Image affichée
0 à 500(2, 0)
6 à 1111(3, 0)
12 à 1720(2, 0)
18 à 2331(3, 0)

La division entière ralentit le rythme, le reste de la division le ramène à deux valeurs. Aucune variable n’est nécessaire : le compteur d’images suffit, et deux joueurs animés resteraient synchronisés.

Retourner un sprite

Inutile de dessiner un personnage tourné vers la gauche : la même image suffit, à condition de la retourner. pyxel.blt() accepte une largeur négative, ce qui inverse le dessin horizontalement, sans le décaler.

if self.is_facing_right:
    width = self.width
else:
    width = -self.width

La direction est retenue au moment de la lecture des touches : appuyer sur la flèche gauche met is_facing_right à faux, la flèche droite à vrai. Le personnage garde donc son orientation après le relâchement de la touche.

Pourquoi une largeur négative

Une largeur négative indique à Pyxel de lire les pixels de droite à gauche. L’image occupe exactement le même rectangle à l’écran : seule son orientation change. La hauteur pourrait être négative de la même façon, pour un sprite retourné verticalement.

Un niveau deux fois plus large que l’écran

Le niveau mesure 64 cases de large sur 32 de haut, soit 512 × 256 pixels. La fenêtre n’en montre que 256 pixels de large : il faut choisir quelle portion afficher.

  • Les objets gardent leurs coordonnées du monde : la pièce de la seconde moitié est à x = 456, même si elle est hors de l’écran.
  • L’écran, lui, va de 0 à 255. Un objet n’y apparaît que si sa position du monde, diminuée du décalage, tombe dans cet intervalle.

La constante LEVEL_WIDTH passe de 32 à 64 : le niveau dessiné, la limite du joueur et le balayage des pièces s’appuient dessus. Le programme trouve ainsi les dix-huit pièces du niveau, neuf par moitié.

La caméra

camera_x = pyxel.clamp(
    self.player.x + self.player.width // 2 - pyxel.width // 2,
    0,
    self.level.width - pyxel.width,
)
pyxel.camera(camera_x, 0)

Le calcul place le centre du joueur au centre de la fenêtre : la position du joueur, plus la moitié de sa largeur, moins la moitié de l’écran. pyxel.clamp() empêche ensuite la caméra de sortir du niveau : jamais avant 0, jamais après 256.

Position du joueurCalculCaméra
x = 88 + 4 - 128 = -1160
x = 100100 + 4 - 128 = -240
x = 300300 + 4 - 128 = 176176
x = 504504 + 4 - 128 = 380256

pyxel.camera(x, y) ne déplace aucun objet : elle décale le dessin. Toutes les opérations de dessin suivantes sont translatées de -x et -y, ce qui simule un déplacement de la vue. Les attributs x et y des objets ne changent pas.

La caméra n’est pas un objet du jeu

Elle ne fait partie ni du niveau ni du joueur : c’est un réglage global de Pyxel. Elle s’applique à tout ce qui est dessiné ensuite, y compris les textes, c’est pourquoi il faut la remettre à zéro avant de dessiner l’interface.

Revenir à l’écran pour les textes

self.player.draw()

pyxel.camera()

Appelée sans argument, pyxel.camera() remet le décalage à zéro. Le score, les pièces restantes et le message de défaite restent ainsi collés aux bords de la fenêtre, quel que soit l’endroit du niveau affiché.

L’ordre du dessin reste celui de la leçon 7 : fond, niveau, pièces, ennemis, joueur, puis interface.

Le joueur dans le niveau, plus dans la fenêtre

self.x = pyxel.clamp(
    self.x,
    0,
    self.level.width - self.width,
)

Depuis la leçon 3, le joueur était retenu par les bords de la fenêtre. Avec un niveau plus large, cette limite deviendrait un mur invisible au milieu du décor. Le joueur est désormais retenu par les bords du niveau : 0 à gauche, 504 à droite.

La collision avec la tilemap, elle, ne change pas : move_player() utilise toujours la liste des tuiles solides.

Erreurs fréquentes

L’interface défile avec le décor

Oublier pyxel.camera() avant les textes les fait sortir de l’écran dès que la caméra avance. Le score disparaît vers la gauche en même temps que le décor.

La caméra montre du vide

Sans pyxel.clamp(), la caméra devient négative au début du niveau ou dépasse la fin : le décor laisse apparaître une bande de fond uni sur le bord de l’écran.

La caméra calée sur le coin du joueur

Utiliser self.player.x sans ajouter la moitié de sa largeur place le joueur au bord gauche de l’écran, et non au centre. Le personnage reste collé au bord, ce qui rend le défilement désagréable.

Le niveau reste coupé à 256 pixels

Oublier de passer LEVEL_WIDTH à 64 laisse le joueur buter sur une limite invisible au milieu du décor, et le programme ne trouve que neuf pièces au lieu de dix-huit.

Le sprite retourné saute de côté

Avec une largeur négative, Pyxel dessine dans le même rectangle : ne décalez pas x en même temps. Ajouter self.width à la position ferait glisser le personnage d’une tuile à chaque changement de direction.

L’animation ne démarre pas

Appeler choose_tile() avant la mise à jour de dx et de is_on_ground lit les valeurs de l’image précédente : le personnage garde une image en retard, ou reste figé au repos pendant la marche.

Expérimentations

Ces modifications sont facultatives.

Une animation plus rapide

ANIMATION_SPEED = 3

Le changement d’image a lieu toutes les trois images au lieu de six : les jambes s’agitent deux fois plus vite. Une valeur de 1 donne une animation frénétique, une valeur de 15 un pas très lent.

Trois images de marche

PLAYER_WALK_TILES = [(0, 0), (2, 0), (3, 0)]

La liste contient maintenant trois tuiles, mais l’index reste calculé avec % 2 : la troisième ne s’afficherait jamais. Il faut écrire % len(PLAYER_WALK_TILES) pour que l’animation parcoure toute la liste.

Animer l’ennemi

La banque d’images ne contient qu’un dessin d’ennemi. En dessiner un second dans l’éditeur, par exemple en tuile (5, 0), puis alterner :

index = pyxel.frame_count // 8 % 2
tile_x = 4 + index

Les deux images se suivent sur la ligne 0 : l’index sert directement de décalage de colonne.

Afficher la caméra

pyxel.text(4, 28, f"Caméra : {camera_x}", TEXT_COLOR)

Cette ligne, ajoutée après la remise à zéro, montre la valeur du décalage. Elle vaut 0 dans la première moitié du niveau, puis augmente jusqu’à 256.

Une caméra qui suit avec du retard

self.camera_x = self.camera_x + (camera_x - self.camera_x) // 4

En conservant la caméra dans un attribut et en la rapprochant progressivement de sa cible, le défilement devient plus doux. La caméra semble avoir de l’inertie quand le joueur change de direction.

Un niveau plus haut que l’écran

pyxel.camera(camera_x, camera_y)

La caméra accepte deux valeurs. Avec un niveau de 64 cases de haut, la même formule appliquée à y fait défiler le décor verticalement. Il faut alors penser à dessiner le niveau sur toute sa hauteur.

À retenir

  • Une animation est une suite d’images choisies à tour de rôle.
  • pyxel.frame_count compte les images depuis le lancement : c’est une horloge.
  • // ANIMATION_SPEED % 2 transforme ce compteur en index de 0 ou 1.
  • Une largeur négative retourne un sprite sans le déplacer.
  • Les objets gardent des coordonnées du monde ; la caméra décale le dessin au dernier moment.
  • pyxel.camera() sans argument remet le décalage à zéro : indispensable avant l’interface.
  • pyxel.clamp() empêche la caméra de dépasser les bords du niveau.
  • Le joueur est limité par le niveau, plus par la taille de la fenêtre.

Dans la prochaine leçon, le jeu reçoit son interface complète : un écran titre, un écran de fin, une musique lancée au bon moment et un compteur de vies ou de temps.
